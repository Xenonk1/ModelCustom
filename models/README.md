Place your model folders here. Each add-on ped needs its original `peds.meta`
and matching `.yft`, `.ydd`, `.ytd`, `.ymt` files. Optional `.ycd` files are supported.

```text
models/
  my_ped/
    model.txt
    peds.meta
    my_ped.yft
    my_ped.ydd
    my_ped.ytd
    my_ped.ymt
```

Use the model's actual internal name in `model.txt`; the folder can have a
different display name. Keep the files and metadata from the same pack.
Restart FiveM after adding or changing model assets, then select the model in F4.

To see another user's model, install the identical pack and configure the same
relay URL. Model assets are not downloaded or shared by the plugin.

This repository and its release ZIP do not include third-party character models.
